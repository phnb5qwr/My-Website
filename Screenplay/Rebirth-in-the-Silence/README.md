# Rebirth in the Silence
A psychological drama film project by Pi.

This project is a personal creative exercise.

— Introduction (5min)
— Early Signs (15min)
— Hell Sequence (60min incl. 5min elder narration)
— Warmth of the City (30min)
— Final Quiet (10min)
